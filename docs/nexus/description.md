# FFRS Unstraightened

An English dialogue mod for FINAL FANTASY RESONANCE that rewrites a small number of lines to drop presumed straightness and compulsory-romance framing, keeping the story, relationships and characters as written.

Content tag: AI-Generated Content

Disclosure: the rewrites were made with AI models trained on the characters' voices.

Game build: $build_id
Version: $tag

## Install

Copy FFRS-Unstraightened_P.pak, FFRS-Unstraightened_P.utoc and FFRS-Unstraightened_P.ucas into FFRS/Content/Paks/~mods in the game folder.
